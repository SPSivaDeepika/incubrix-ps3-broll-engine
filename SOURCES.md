# Sources, dependencies, and rights

- FastAPI: https://fastapi.tiangolo.com/ — API framework; see package licence before submission.
- Pydantic: https://docs.pydantic.dev/ — request validation.
- Requests: https://requests.readthedocs.io/ — HTTP client.
- Pillow: https://pillow.readthedocs.io/ — generated graphic fallback.
- FFmpeg: https://ffmpeg.org/ — audio/video encoding and normalization; check the exact build configuration/licence of the binary used.
- eSpeak NG: https://github.com/espeak-ng/espeak-ng — offline text-to-speech; verify licence and commercial-use compatibility for the selected distribution before submission.
- Optional stock source: Pexels API and Pexels License: https://www.pexels.com/api/documentation/ and https://www.pexels.com/license/. Only use downloaded assets after reviewing applicable API terms and each asset's source metadata. Keep the source URL and attribution in `timeline.json`.
- No external dataset is bundled. Generated fallback visuals are created locally by this app.

This list is a starter disclosure and must be checked against the exact versions/builds used before final submission.
